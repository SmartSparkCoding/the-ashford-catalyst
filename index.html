How to add editions in JavaScript

Edit editions.js and add another item to the editions array, or call the helper function from the browser console.

window.registerCatalystEdition({
  number: "5",
  information: "Special report on space and flight",
  date: "2026-05-12",
  file: "editions/issue-5.pdf",
  articles: ["Space science", "Flight tests"]
});
